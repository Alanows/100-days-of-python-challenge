
# Lottery Simulator 🎰

A simple Python lottery simulator that generates a random winning ticket and keeps trying random combinations until it matches the winning one.

## Features
- Uses letters (`A-Z`) and numbers (`0-99`) as possible lottery values.
- Generates an 8-character winning ticket.
- Simulates random attempts until the correct ticket is found.
- Displays:
  - The winning ticket
  - Number of attempts needed to win
